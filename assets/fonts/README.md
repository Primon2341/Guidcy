# Guidcy fonts

The `*-inr.woff2` files are variable-weight, U+20B9-only subsets of the same Google Fonts families used by Guidcy. They add the missing Indian rupee glyph without replacing the existing Latin subsets or relying on a different fallback face. Generated by the Google Fonts CSS2 API with `text=₹` and the existing weight ranges; downloaded 2026-09-19.

- DM Sans: 100–1000 (`OFL-DM-Sans.txt`)
- Cormorant Garamond: 300–700, normal and italic (`OFL-Cormorant-Garamond.txt`)
- Plus Jakarta Sans: 200–800 (`OFL-Plus-Jakarta-Sans.txt`)

Source: https://fonts.googleapis.com/css2?family=DM+Sans:wght@100..1000&family=Plus+Jakarta+Sans:wght@200..800&family=Cormorant+Garamond:ital,wght@0,300..700;1,300..700&text=%E2%82%B9&display=swap
